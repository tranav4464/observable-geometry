## Documentation structure

| Directory | Purpose |
|---|---|
| [`tks/`](tks/) | Submission, demo, pitch, handoff, and packaging instructions |
| [`foundation/`](foundation/) | Architecture, mathematics, validation, and foundation decisions |
| [`planning/`](planning/) | Master plans, execution plans, and Track B handoff material |
| [`track-a/`](track-a/) | Track A completion and audit records |
| [`track_b/`](track_b/) | Track B protocols, gate records, results, and machine-readable evidence |
| [`reviews/`](reviews/) | Build reviews, remediation reviews, and future-work feedback |

Files under `track_b/` retain their historical evidence-oriented names because they are cited by audit records. Current public navigation uses the folders above.

The portable TKS bundle excludes licensed model arrays, recordings, ignored run outputs, and the larger adjacent research workspace. Historical evidence links that point to those local materials resolve only in the full research workspace; this is not an indication that those artifacts are redistributed in the bundle.
