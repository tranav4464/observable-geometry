# B0 closeout: select and bound the build target

> **Superseded on 23 October 2026. Historical NeuroFlowNet/WBEN route only.** The active build is GBFs reproduction and nominal source-distinguishability under one verified participant-specific head model. Do not use this file as an active task, protocol, or gate contract. See `PROJECT_DEFINITION.md`, `GBF_BUILD_PLAN.md`, and `GATE_REGISTER.json`.

**Decision: PASS for a clean-room NeuroFlowNet method-implementation/challenge route.** Track B will anchor on one existing model family and one native output: the conditional normalizing-flow method described by He et al. for predicting recorded iEEG waveforms from simultaneous scalp EEG. The project will independently implement the paper's method from its published description and will not copy or adapt the unlicensed author-repository code. NEMAR's companion record confirms that the original nine-subject G-Node cohort is aligned to `ds004752` participants `sub-01` through `sub-09`, and the existing crosswalk audit maps paper subjects S1/S6/S9 to `sub-01`/`sub-06`/`sub-09`. The data-lineage question is resolved, while paper-level experimental reproduction remains unverified until the pipeline and reported metrics are matched. This is a route choice, not a claim of algorithmic novelty, successful implementation, or scientific performance.

## Selected build

- **Software workspace:** the existing `observable_geometry` project. Track A remains sealed and is retained as infrastructure.
- **Scientific baseline:** NeuroFlowNet's conditional normalizing-flow model, implemented clean-room from the paper and evaluated on the pinned NEMAR release. The selected paper participants are available in the pinned release; paper-level experimental reproduction remains unverified pending pipeline/metric fidelity checks.
- **Measured endpoint:** a predictive distribution for recorded intracranial contact waveforms, conditional on simultaneous scalp EEG, on the bandwidth and preprocessing that can be defended from the dataset and paper.
- **Challenge question:** test whether that distribution remains predictive and reliable when a verbal-working-memory set size is absent from a participant's training data. B2 must establish exact eligibility, splits, inputs, target scaling, metrics, alternatives, prior-art boundary, and an independent protocol challenge before fitting.
- **Contribution status:** no new algorithm is accepted. The candidate project contribution is a real-data, test-time-valid held-load recoverability and uncertainty evaluation. It must distinguish normalized waveform shape from absolute-amplitude prediction and compare raw with established calibration baselines. Novelty is unverified and must not be claimed.

## Why this route

The endpoint fits the model's native output and is directly measurable against paired real iEEG recordings. The supplementary 200 Hz development audit confirms corrected event alignment and real-signal shapes in 14 sub-01–03 sessions, with 46–50 paired trials per session. That demonstrates data-grid compatibility only.

WBEN remains important prior art, but its principal output is regional network state/connectivity and this dataset does not reveal ground truth for unobserved edges. Pairing its reproduction with a separate contact-waveform task created two estimands and has been withdrawn as the primary build. GBFs remains a separate source-imaging comparator and Track A foundation. REA is a software reverse-engineering toolkit, not a neural model or task, so it is not the scientific build base.

## Known limitations and controls

- NeuroFlowNet's paper reports within-subject held-trial and held-session tests, not a held-out working-memory load. Its results preempt generic waveform reconstruction and session-transfer novelty claims. NEMAR's cohort companion confirms the source-cohort alignment; our reproduction of the paper's pipeline and results remains unverified.
- Its reported 90% predictive intervals have empirical coverage of about 0.38–0.43 on the selected subjects. This motivates a reliability challenge but does not make uncertainty calibration novel.
- The inspected public repository has no declared license. It will not be reused. The repository's validation path also uses held-out target segment statistics for unnormalization and has a sampling-rate filter mismatch. These are findings about the inspected code snapshot; they do not prove the published paper's tables were generated by that exact code.
- The project will not use target iEEG statistics at test time. B2 must specify a training-only normalization path and separately score scale-invariant shape and any real-unit amplitude predictions.
- Exact held-load overlap with some neighboring literature remains unknown because a cited full paper's methods could not be obtained. Unknown overlap is not evidence of novelty.
- Confirmation participants remain sealed until B5 protocol lock. No Track B model has been fit.
