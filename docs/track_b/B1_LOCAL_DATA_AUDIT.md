# B1 local data and physical-task audit

**State: open, 2026-10-22.** This is a filesystem inventory plus task-fit check; it does not establish trial quality, forward accuracy or independent validation.

## What is actually present

The repository checkout contains metadata and 65-byte data pointers for seven participant forward files. At the initial audit, the separate numerical payload location contained only a 177,020,482-byte `sub-01_fwd.fif` and eleven sub-01 EEG epoch arrays. On 22 October 2026, a checksum-verified acquisition completed for **all 56 listed forward/epoch files for sub-02 through sub-07, totaling 9,601,616,555 bytes**. `outputs/track_b/data_acquisition/sub-02_03_04_05_06_07_both.json` records the dataset MD5 for each file. Sub-01 is development data because Track A results already informed the research direction.

This inventory was checked with PowerShell `Get-Item` on each forward pointer and payload, and `Get-ChildItem -Recurse -File` on each payload epoch directory. The exact metadata counts of eligible matched-current sites in the architecture remain *screening counts*, pending event and trial-level audit.

The retrieved sub-02 forward file passed its published size and MD5 pointer check and loads as a **256-channel, 8,196-source, free-orientation** MNE forward with a `(256, 24,588)` lead-field matrix. The sub-02 run-01 `.npy` header is `(43, 256, 2081)`, `float64`; its metadata lists 8,000 Hz, voltage units, and event zero at 0.25 s. These are **file and format checks only**. No held-out waveform values or pair-confusion outcomes were examined. The free-orientation forward is useful for testing an equivalent-dipole approximation, but it does not make the existing cortical source grid a validated bipolar-injection generator.

The separate contract pass `outputs/track_b/data_acquisition/contract_sub-02_03_04_05_06_07.json` rehashed all 56 files and checked `.npy` headers, metadata trial counts, channel names/order against each forward, voltage units, 8 kHz sampling, event timing and single condition per run. It passed for **50 runs and 2,004 trials**. All six forwards have 256 channels, 8,196 sources and free orientation. Good-channel counts across runs vary by participant (sub-02 195–199; sub-03 211–223; sub-04 227–246; sub-05 201–217; sub-06 172–184; sub-07 162–187). This script does not read EEG sample values or calculate outcome scores.

The pre-outcome SHA-256 inventory `outputs/track_b/data_acquisition/sha256_sub-02_03_04_05_06_07.json` records byte identities for all **56 files / 9,601,616,555 bytes** after checking each size and dataset MD5 pointer. It was generated before any held-out EEG values were interpreted. This fixes input provenance for later split/protocol checks; it does not freeze the method or make the data an independent confirmation by itself.

The all-participant geometry audit `outputs/track_b/data_acquisition/geometry_sub-01_02_03_04_05_06_07.json` checks forward/EEG-electrode agreement, coordinate units, invertible head-to-surface transforms, contact identities and cortical-grid proximity using metadata and forwards only. It passed: maximum sensor-coordinate discrepancy **0.00866 mm** and maximum contact-pair-midpoint-to-grid distance **3.91 mm** (none over 10 mm). This establishes consistent frames and close candidate grid points, **not** accuracy of the electrical source generator. B1 still needs a physical-model adequacy criterion and the evaluation split/protocol.

**Reproducible metadata-only eligibility screen.** `scripts/track_b/audit_b1_eligibility.py` reconciles each validated contract run against the event and channel TSVs, then reports every same-current contact-pair group and the good-channel intersection across all runs. It reads no EEG array values and computes no pair scores. All six possible test participants have at least one group with three or more sites and 20 or more metadata trials per site. The largest groups contain 3–8 sites, but the minimum trial count ranges from 21 to 42. The smallest across-run good-channel intersection is **140** (sub-07); the other participants have 156–212. Sub-02 has tied three-site groups at both 0.5 mA and 1 mA, so the summary table's 0.5 mA row is not a unique optimum. Exact conditions and counts are in `outputs/track_b/data_acquisition/eligibility_sub-02_03_04_05_06_07.json`.

This establishes metadata feasibility only. The candidate site pairs are dependent, several conditions have modest trial counts, and each condition is represented by one acquisition run in this screen. It therefore does not justify a flexible calibration model or a population-level accuracy claim. Any trial-level result must first pass a development-only signal-quality and negative-control screen; the final sample/power decision must be frozen before test outcomes are examined.

## Physical task

The Localize-MI endpoint is the scalp potential from a bipolar intracranial stimulation pulse. It tests discrimination of known contact-pair stimulation artifacts. It does **not** by itself validate localization of spontaneous neural activity, imagination or a true cortical generator. The fixed cortical-normal columns used in Track A are a diagnostic proxy. A prior scalp/intracranial validation study used a **free equivalent dipole** with participant-specific FEM and documented conductivity/depth sensitivity; an explicit positive/negative current-source model is a second physical candidate. Neither can be assumed accurate for Localize-MI without checking sensor residuals and perturbation sensitivity. Sources: [2023 validation](https://pubmed.ncbi.nlm.nih.gov/36824389/); [artifact model](https://pmc.ncbi.nlm.nih.gov/articles/PMC9596776/).

**Published signal-chain check (2026-10-22).** The dataset authors' public preprocessing script confirms that raw EEG is high-pass filtered at 0.1 Hz (with additional 50/100/150/200 Hz notch filtering for sub-05 and sub-07), initially epoched from -300 ms to +50 ms around the stimulation trigger, baseline corrected over -300 to -50 ms, bad channels interpolated, and epochs realigned to peaks in the -10 to +10 ms window. The realignment function then retains -250 to +45 ms; the BIDS export crops this to +10 ms. The local BIDS sidecars independently describe 8 kHz voltage recordings, a 0.1 Hz low cutoff, baseline correction, and 260 ms epochs with the trigger 250 ms after the epoch start. Thus the actual distributed samples cover approximately -250 to +10 ms relative to the stimulation pulse. This is a short, processed, pulse-locked response window, not continuous resting/task EEG; it includes the stimulation artifact and only about 10 ms of post-trigger signal. The present sub-01 adequacy analyses use a training-selected post-trigger sample to model the scalp topography. Their target must be called a **pulse-evoked scalp response / stimulation-artifact distinguishability task**, with the artifact contribution explicitly acknowledged. A pass can support a narrow statement about discrimination under this stimulation protocol and recording chain. It cannot support general scalp source recoverability, spontaneous neural activity, imagination, or BCI decoding. This is corroborated by the original dataset description, which presents the data as known-location intracranial stimulation and illustrates the scalp stimulation artifact, and by the authors' processing code. Sources: [Localize-MI paper](https://www.nature.com/articles/s41597-020-0467-x); [authors' preprocessing script](https://github.com/iTCf/mikulan_et_al_2020/blob/master/_01_preprocess.py); [BIDS export crop](https://github.com/iTCf/mikulan_et_al_2020/blob/master/fx_bids.py).

The code-level check also narrows what an apparent source-model fit means: it predicts a processed scalp response after baseline correction, peak realignment and cropping, not an unfiltered physical field at an arbitrary instant. Any candidate generator comparison must apply the same channel reference, baseline operation, time alignment and channel mask to its prediction, or declare an explicitly justified alternative. Preserve the distinction between the initial -300 to +50 ms processing epoch, the peak-realigned -250 to +45 ms epoch, and the distributed -250 to +10 ms BIDS epoch.

**Sub-01 development-only adequacy result.** `scripts/track_b/check_sub01_dipole.py` fits source amplitude (or, for a free dipole, three orientation coefficients) on alternating training trials at a training-selected pulse time, then scores the other trials at that same time. The same channel reference and training-baseline whitener are used throughout. Across six 1 mA sites, median held-out whitened topography `R²` was **0.577** for a dipole oriented along the contact-pair axis at the nearest cortical-grid point, **0.162** for Track A's fixed cortical-normal column, and **0.615** for a freely fitted dipole. Full per-site values and split details are in `outputs/track_b/development/sub01_dipole_adequacy.json`. One site favored the fixed normal over the contact axis, and the free model has extra fitted parameters. This supports contact-axis orientation as a development candidate and shows the old fixed-normal proxy is a weak physical generator for most sites. It does **not** show that an equivalent dipole is a complete current-injection model or that any held-out participant will behave similarly. The next physical test is residual topology, conductivity sensitivity, and comparison to an explicit bipolar model.

**Contiguous-trial sensitivity.** Replacing odd/even trials with the first half for fitting and the second half for scoring gave median held-out whitened `R²` of **0.597** (contact axis), **0.173** (fixed normal), and **0.651** (free orientation); the contact axis beat the fixed normal at five of six sites. See `outputs/track_b/development/sub01_dipole_adequacy_contiguous.json`. The ranking survived this split change, but both halves still share a participant and recording run. This is neither independent validation nor evidence that the source physics is adequate.

**Residual falsification.** The same script now records the signed cosine between train and held-out residual scalp topographies after applying the training-fitted prediction. Under the contiguous split, median residual cosine is **0.999** for both contact-axis and free dipole (all six sites approximately 0.998–1.000), even though the free dipole explains more total signal. The alternating split is similar. Thus, a large fraction of the measured pulse topography is *reproducibly missing* from these simple models on sub-01; the residual cannot be dismissed as independent trial noise. This diagnostic does not identify whether missing structure arises from bipolar-injection physics, head conductivity, amplifier behavior or another systematic effect. It rules out declaring the equivalent dipole physically adequate from its relative `R²` alone. The next comparison must include an explicit bipolar-current model or a defensible alternative that removes this structured residual, plus perturbation and reference checks. No test-participant waveforms were inspected.

**First bipolar-current comparator.** A deliberately simple infinite, homogeneous-conductor prediction places equal and opposite point currents at the two contacts: `V(r) ∝ 1/|r-r₁| − 1/|r-r₂|`. Contact positions are transformed into the forward's head frame; scale is fitted on training trials. An analytic sign/axis unit test passes. On sub-01, its median held-out whitened `R²` is **0.533** with alternating trials and **0.549** with contiguous trial halves, below the contact-axis dipole's **0.577/0.597**. Its residual pattern is also nearly identical across train/test halves. This rejects the *homogeneous point-source approximation* as a remedy on these six development sites. It does not reject an explicit bipolar model with layered/anisotropic head physics or prove which physical feature causes the mismatch. See `src/observable_geometry/track_b/physical.py`, `tests/test_track_b_physical.py` and the two sub-01 adequacy JSONs.

Cross-site residuals are **not** one identical global topography: among the 15 pairs of sub-01 sites, median signed residual cosine is about **0.38** for the contact-axis model and **0.33** for the free dipole, whereas each site's own train/test residual cosine is about **0.999**. Thus the missing component is repeatable within a site but heterogeneous across sites. A single shared nuisance template is unlikely to explain all six residuals. These pairwise similarities are descriptive and dependent, not six independent physical diagnoses.

The next, three-layer BEM source-sink test has been completed on sub-01 development data and is documented in [B1_BEM_DEVELOPMENT.md](B1_BEM_DEVELOPMENT.md). Its median held-out whitened `R²` was **0.568** (alternating) and **0.600** (contiguous); the residual remained highly repeatable. The candidate conductor is numerically feasible but still not an adequate physical explanation of the pulse recording. The first layered run had a detected metres-versus-millimetres error and is preserved explicitly as invalid; only the corrected runs support these numbers.

## B1 pass conditions

1. Obtain numerical payload for a prespecified set of participants beyond sub-01, verify hashes, file readability, channel identity, units, sampling frequency, event timing and matched-current trial counts. Do not inspect outcome-confusion results until the test split and protocol lock are set.
2. Define contact-pair coordinates and physical source orientation in the same coordinate frame as the forward model. Verify transforms and millimetre/metre units with independent landmark checks.
3. On sub-01 development only, compare free-dipole and explicit-injection predictions where implementable; report cross-validated sensor fit, residual topography, sensitivity to conductivity/reference, and failures. A dipole approximation may be accepted if it passes frozen adequacy thresholds; full injection physics is not an automatic requirement.
4. State the narrow artifact claim in the protocol. A separate physiological dataset and validation are required for any extension to cortical source recoverability.

**Decision now:** B1 remains `IN_PROGRESS`. The only currently defensible Localize-MI route is a narrowly named pulse-evoked response / stimulation-artifact discrimination benchmark. It is not a substitute for Route N physiological validation. Proceed with method derivation and development fixtures only if every claim is restricted to that target; do not make confirmatory participant claims or a novelty announcement before physical adequacy, split lock and statistical feasibility pass.

## Statistical feasibility warning before split lock

The largest same-current group for sub-02 has only three sites, hence three dependent site pairs; sub-06 and sub-07 each have six dependent pairs. Even a successful file audit will not make pairwise error estimates precise or turn pairs into independent replicates. A flexible learned calibration map is not credible from sub-01's fifteen development pairs alone. B1/B4 must choose and freeze either a very low-dimensional calibration rule with explicit uncertainty, a participant-grouped cross-validation design with a later independent replication, or a narrower ranking/feasibility endpoint. This decision must be made before inspecting held-out pair-confusion outcomes; it cannot be rescued by a favorable post-hoc threshold.
