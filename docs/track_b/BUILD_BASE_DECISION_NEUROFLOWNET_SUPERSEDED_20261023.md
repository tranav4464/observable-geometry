# Track B build-base assessment

**Current state (2026-10-23): B0 passed for a NeuroFlowNet clean-room method-implementation/challenge route; B1 passed for bounded real-data feasibility.** NEMAR's original-cohort companion confirms that the NeuroFlowNet paper's nine-subject source cohort is aligned to `ds004752` participants `sub-01` through `sub-09`, including the selected S1/S6/S9 subjects. The data-lineage question is resolved; paper-level experimental reproduction is still unverified until pipeline and metric fidelity are checked. The earlier WBEN selection paired regional-network reproduction with a separate contact-waveform predictor. Those different estimands did not form one coherent primary build and are superseded. No novelty is presumed.

## Working selection

- **TKS software project:** continue in this `observable_geometry` workspace and its `src/observable_geometry/track_b/` package. It already contains the Track A foundation, Track B gate system, classical baselines, physical-model utilities, tests, and the isolated GPU environment. Track A release artifacts remain sealed.
- **Primary scientific baseline:** a clean-room implementation of NeuroFlowNet's conditional normalizing-flow method, selected for scalp-to-recorded-iEEG waveform prediction on the pinned NEMAR release. The selected source participants are available in the release. This selection does not establish paper-level experimental reproduction, model performance, or novelty.
- **Existing code comparator:** the vendored upstream GBFs implementation at `vendor/GBFs/` (BSD 3-Clause) and the local Track A adaptation. GBFs addresses EEG/MEG source imaging using geometry-derived basis functions, while WBEN estimates latent regional dynamics and connectivity from scalp EEG plus iEEG. Keep their estimands separate.
- **REA disposition:** do not use REA as the neurotech model or clone it into this project. Its official repository describes a general agent/MCP toolkit for reverse engineering applications, binaries, runtime behavior, and model-artifact metadata. It does not provide an EEG/BCI model, neural dataset, or brain-inference algorithm. It may be useful later as an optional software-inspection tool if a suitable target binary or app exists, but it is not necessary to reproduce WBEN from the paper.

## Why this is a bounded reproduction/challenge route

NeuroFlowNet is selected as the clean-room baseline candidate because its native output is the measured iEEG waveform, which can be checked directly against paired real recordings. The held-load question tests a specific domain shift that its paper's random held-trial and held-session evaluations do not report. Its prior work prevents generic waveform-reconstruction or session-transfer novelty claims. The candidate contribution is a test-time-valid evaluation of held-load waveform recoverability and predictive reliability, with normalized shape distinguished from absolute amplitude. Whether the exact task is new remains unverified. NEMAR's companion record maps the original nine-subject source cohort to `ds004752` participants `sub-01` through `sub-09`; the selected S1/S6/S9 participant mapping is documented in the NeuroFlowNet cohort audit. No synthetic datasets are active evidence.

**Route correction:** the prior two-part proposal (WBEN reproduction plus separate contact-waveform prediction) was withdrawn because its outputs and estimands differ. B0 now selects NeuroFlowNet's conditional normalizing-flow method as one clean-room baseline and recorded iEEG waveform prediction as the matching endpoint. The 200 Hz compatibility check passes on development sessions; it does not validate the model. NeuroFlowNet's inspected repository is unlicensed, so no code is reused. Its reported interval undercoverage and target-scale handling motivate a test-time information audit, but no new algorithm is accepted. The route decision is recorded in `outputs/track_b/20261023T_b0_single_route_reassessment/SESSION.md`.

**Comparison rule:** the build must have one primary model and one primary estimand. A contact-waveform score cannot validate WBEN regional-network estimates, and these should not be joined into one headline project. The all-participant schema audit confirms channel-label availability only; it does not establish model performance or trial eligibility. See D065 and `outputs/track_b/20261023T_b2_all_participant_channel_schema_audit_v2/SESSION.md`.

**Superseded proposal:** the earlier two-part WBEN plus contact-prediction design remains archived in `outputs/track_b/20261023T_b2_build_path_alignment_decision/SESSION.md`. No Track B model has been fit, and no training, performance, or novelty result exists.

The coverage- and mismatch-conditioned edge-support proposal is not an approved innovation. A primary-source review confirms close overlap with graph recovery under partial observation (Machado et al., AAAI 2023) and observation-error magnification for partially observed network dynamics (Berry & Sauer, SIAM JADS 2025). A weighted frequency of edge inclusion across perturbations is a comparator/diagnostic. Any extension must be mathematically distinct from edge magnitude, ordinary stability, partial-observation/observability methods, and WBEN, and improve a prespecified endpoint at matched graph sparsity and tuning budget. Otherwise the project remains a rigorous software reproduction, robustness benchmark, and failure-boundary map. See [`B0_CLOSEOUT.md`](B0_CLOSEOUT.md).

## Implementation boundary

Keep implementation under `src/observable_geometry/track_b/`, with its own tests and commands. Do not modify the sealed Track A release or vendor source. Record the exact paper version and every implementation interpretation. The first numerical implementation is CPU float64; GPU acceleration follows only after analytical fixtures and an independent CPU oracle pass. The current CUDA smoke check verifies the runtime, not scientific correctness or speed.

No participant signal fitting starts until B2 freezes the mathematical specification and the required independent challenge passes. Active evaluation uses real recordings only. Any confirmatory held-out evaluation requires a separate B5 lock.

## Decision status and next action

**Current:** The software workspace remains `observable_geometry`; NeuroFlowNet is selected as the clean-room baseline candidate. GBFs remains comparator/infrastructure and REA is excluded as a neural model. B0 passed; B1 passed for bounded data feasibility.

**Not decided:** whether any mathematically distinct extension survives implementation and matched testing. The dataset supports the proposed event-grid representation, but this is not evidence of model validity or performance.

**Next gate action:** finish B2 with a NeuroFlowNet-aligned endpoint, a target-statistics firewall, held-load split, matched baselines, reliability metrics, failure criteria, and independent protocol challenge. Keep confirmation outcomes sealed until B5 lock. Do not use novelty language before the evidence supports it.
