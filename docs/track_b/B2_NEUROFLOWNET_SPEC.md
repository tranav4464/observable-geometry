## 1. Question and bounded claim

For a participant with simultaneous scalp EEG and depth iEEG from a verbal-working-memory task, does a scalp-conditioned probabilistic waveform model trained on two set sizes predict the recorded iEEG contacts at a third, unseen set size, and do its predictive intervals remain reliable under that load shift?

The target is the **measured reference-dependent contact waveform** in the paired recording, not a noise-free neural source. This is within-participant condition transfer because each participant's other set sizes are available for model fitting. It is not zero-shot subject transfer, anatomical source localization, proof of a unique brain mechanism, or decoding of arbitrary thought. “Common reference” below means the acquisition's declared intracranial reference for the chosen contacts; it does not mean a common electrical reference shared by scalp EEG and iEEG.

The exact held-load overlap with all neighboring literature is unresolved. The software may report a reproducible held-load challenge result, but it must not claim priority or algorithmic novelty. The bounded contribution is a leakage-controlled evaluation of prediction on a set size omitted from fitting, including whether a correctly paired scalp recording adds value beyond an empirical no-input distribution and temporal baselines. It is a computational benchmark, not a new flow algorithm. This evaluation estimates performance on the omitted condition; without a separate represented-condition reference it cannot attribute any performance difference specifically to changing load.

## 2. Existing baseline and candidate contribution

### Baseline

Implement the published NeuroFlowNet conditional normalizing-flow architecture independently from the paper. The paper describes a multi-scale conditional flow with affine coupling, invertible 1×1 channel mixing, self-attention, maximum-likelihood training, and conditional sampling. Its reported evaluations use subject-specific held-trial and held-session splits, 1-second windows at 200 Hz, and selected subjects S1/S6/S9. No source from the unlicensed author repository may be copied or adapted. The exact forward/inverse discrepancy and every source-informed implementation choice are recorded in [`B2_PAPER_FIDELITY_MATRIX.md`](B2_PAPER_FIDELITY_MATRIX.md); therefore this project is a clean-room, source-informed adaptation and must not be described as an exact reproduction.

The implementation may be called a **clean-room implementation of the published method** only after an equation-to-code review and a real-development-data check. NEMAR's original-cohort companion confirms that the nine-subject G-Node cohort and subject/session/trial labels align to `ds004752` participants `sub-01` through `sub-09`; the prior cohort audit maps the paper's selected S1/S6/S9 analyses to `sub-01`/`sub-06`/`sub-09`. Dataset lineage is established. Differences in filtering, normalization, amplitude restoration, architecture details, optimizer, and metrics still need to be resolved before claiming experimental reproduction.

### Candidate project contribution

Build a **test-time-valid held-load prediction and reliability evaluation** for the baseline. The candidate addition is a locked information boundary and a real-data evaluation that asks whether the model predicts waveform shape, physical scale, and uncertainty on an unseen load. It is not a new normalizing-flow or conformal algorithm.

The paper reports nominal 90% prediction intervals with empirical coverage 0.381–0.432 for its selected subjects. The inspected public code uses each held-out target segment's own mean and standard deviation when restoring prediction scale, so those native-unit errors are unavailable from scalp EEG alone on that code path. This does not establish how the published paper tables were generated. Our evaluation must never provide test-time target iEEG statistics to the predictor. Test-target mean/scale may be computed after prediction only for an explicitly scale-invariant diagnostic, never to restore the model output or claim an amplitude prediction.

### Formal evaluation object and research decision

For participant `p` and held load `k`, let `D[p,−k]` contain all eligible real training trials from the other two set sizes, and let `T[p,k]` contain the test windows from the held set size. A fitted method `m` returns either a point prediction `x̂ᵐ` or, for the conditional flow, a predictive distribution `qᵐ(X | Y, D[p,−k])`. The estimation target is the paired **recorded contact waveform** `X`, in the dataset's reference-dependent microvolt units; it is neither a latent generator nor an absolute brain potential.

For an eligible contact `c`, the load-fold loss is

`rᵐ[p,k,c] = sqrt(mean_{j,t∈T[p,k]} (x̂ᵐ[p,k,c,j,t] − X[p,k,c,j,t])²) / s[p,c,−k]`,

where `j` indexes held-load windows and `s[p,c,−k]` is that contact's standard deviation computed only from the two outer-training loads. Average `r` equally across eligible contacts to obtain `Rᵐ[p,k]`, then equally across the three held-load folds to obtain `Rᵐ[p]`. A participant-level aggregate is defined only when all three folds meet the shared data-eligibility rules; report any ineligible fold and its reason, and do not silently replace or impute it. A model that fails to return finite predictions in any fold is reported as a model failure; its paired participant contrast is unavailable, and the failure count and affected participants remain visible. Do not remove that participant from other methods' descriptive results. This gives each eligible participant one result and prevents the number of contacts, windows, or samples from being mistaken for the number of independent people.

Within each outer fold, choose `b*[p,k]` from the training-mean, ridge, and temporal-CNN alternatives using mean inner-validation NRMSE only. For the CNN, this mean includes its three prespecified seeds; deterministic baselines contribute their single fit. Resolve ties by the predeclared comparator order. The primary paired comparison is `Δ[p] = mean_k(R^CNF[p,k] − R^b*[p,k])`; negative values favor the flow. Report individual participant values and the participant-bootstrap interval. This is a prespecified comparison of measured-waveform prediction; it is not a new estimator, source-localization score, or claim of biological identifiability.

For nominal central interval level `1−α`, report empirical marginal coverage `Cᵐ[p,k,c,α] = mean_{j,t} 1{X[p,k,c,j,t] ∈ [Qᵐ_{α/2}, Qᵐ_{1−α/2}]}` and its absolute calibration gap `G = |C − (1−α)|`, alongside interval width. Quantiles come from the flow's fixed-seed conditional draws transformed using training-fold target statistics. For CRPS comparisons, each deterministic baseline is represented by a point mass at its prediction, so its CRPS reduces to absolute error; its collapsed interval is not presented as a calibrated uncertainty estimate. Coverage is marginal at a contact/sample coordinate, not joint coverage of an entire waveform or brain state. Aggregate uncertainty by participant; do not use the sample count to create a falsely narrow interval.

The practical research decision is limited: determine whether a model trained for one participant on two set sizes can be described as predicting that participant's recorded contact waveforms at a wholly unseen set size, or whether its claims should remain restricted to represented conditions. This does not support zero-shot use on a new participant. A reliability claim requires coverage and width evidence; a point-score improvement alone is insufficient. The exact acceptance interpretation remains subject to the B2 independent challenge and B5 protocol lock.

**Algebra-only check (not a signal or dataset):** if a contact has `n` held-out coordinates, training scale `s`, and residual vector `(a,0,…,0)`, then `r = |a|/(sqrt(n)s)`. If every residual doubles, `r` doubles; if training-only scale doubles while residuals do not, `r` halves. This verifies the normalization's units and direction without creating neural data. If every prediction exactly matches its target, `r=0`, but that still does not imply that the model recovered a unique source. If the predictor equals the training-mean waveform, its score is exactly the mean-baseline score and `Δ=0` when that baseline is selected. If the held load is outside the training input/target distribution, low empirical coverage or high error is a failure boundary to report, not evidence that an unobserved source has been identified.

## 3. Candidate estimand and outer split

Let participant be `p`, load be `k ∈ {4, 6, 8}`, scalp channels be `e`, iEEG contacts be `c`, and time sample be `t ∈ {1,…,200}`. Each one-second window has scalp input `Y[p,k] ∈ R^(E_p×200)` and paired measured iEEG target `X[p,k] ∈ R^(C_p×200)`, represented in the dataset's microvolt units under its declared common intracranial reference. The target is concurrent in time with the scalp window; the model is not a causal forecast of future activity. The candidate predictor is a participant-specific conditional distribution:

`q[p,k](X | Y; D[p,train])`,

where `D[p,train]` contains trials from the two set sizes other than held-out load `k`. Test-time inputs are scalp EEG windows only. The target outcomes for load `k` are unavailable to training, normalization, tuning, calibration, stopping, and model selection.

Use outer leave-one-load-out folds: hold 4, 6, or 8 out in turn for each eligible participant. Train and tune only on the other two loads. Test-time transfer is within participant; no between-participant generalization claim is made. All sessions from a participant remain in that participant's fold. All windows from a trial stay together. The original task methods define maintenance as `[3.0, 6.0)` relative to trial onset and place the probe at 6 seconds. To prevent the zero-phase iEEG resampling filter from reaching across probe onset, use the guarded two-second interval `[3.95, 5.95)`, represented by samples `[790,1190)` at 200 Hz and split into `[790,990)` and `[990,1190)`. Each output sample has the specified 201-tap FIR support of 50 ms on either side; the final scored sample at 5.945 seconds can therefore depend only on native iEEG through 5.995 seconds, before the probe. This is a 50 ms shift from the historical last-two-seconds interval and must be shown as an adaptation. A pinned event-index audit verified trial/probe alignment across all 686 paired development events in 14 sessions. No reserved events or signal samples were read. See `outputs/track_b/20261023T_b2_task_window_source_audit/SESSION.md` and `outputs/track_b/20261023T_b2_preprocessing_contract_audit_v2/resampling_audit.json`.

Development event/signal data are sub-01 through sub-03 only. The documentary access review found no recorded event-row or signal-sample access for sub-04 through sub-15, but cohort-wide channel metadata, sidecars, manifests, and fixed EDF headers have been inspected. Treat those 12 participants as **outcome-unexposed according to the retained logs**, not completely untouched. No confirmatory event values or signal samples may be opened until a B5 protocol and access-log preflight pass. The records are not an OS-level audit trail; if a future access record shows any confirmatory outcomes were exposed, demote the affected participants before B5.

## 5. Matched baselines

Compare, on the same channels, windows, participant/load folds, and train-only preprocessing:

1. **Training-mean waveform:** for each contact and within-window sample coordinate, take the arithmetic mean over all eligible training windows. It ignores the scalp input. For point prediction, this is the simple no-input baseline.
2. **Training-only empirical marginal distribution:** for each contact, window position (first or second second of the guarded interval), and within-window sample coordinate, sample target values uniformly from eligible training windows pooled across the two training loads. Use this empirical distribution to score marginal CRPS, interval coverage, and interval width. It receives no scalp input and no held-load outcome; its coordinatewise draws do not represent joint temporal or cross-contact dependence. Its point mean equals baseline 1, so it is not entered twice in point-score comparisons.
3. **Pointwise multivariate ridge:** map simultaneous scalp samples to contact samples at the same time point. Standardize from training-fold statistics. Fit an intercept and coefficients by minimizing `||Y−XB||_F² / (N·C) + λ||B||_F²`, where `N` is the number of training time samples and `C` the number of output contacts; the intercept is unpenalized. Select `λ` from `{1e−4,1e−3,1e−2,1e−1,1,10}` using only mean inner-validation NRMSE, with ties choosing the smaller λ. Solve the selected objective in float64 with Cholesky when positive definite and otherwise an SVD solve of the same objective; record the branch.
4. **Shallow temporal CNN:** input `[batch,8,200]`, `Conv1d(8,128,kernel_size=7,padding=3) → GELU → Conv1d(128,128,kernel_size=7,padding=3) → GELU → Conv1d(128,C_contacts,kernel_size=1)`. This preserves the original short-receptive-field baseline; its effective receptive field is 13 samples (65 ms) at 200 Hz.
5. **Full-window temporal CNN:** six same-length Conv1d/GELU blocks with hidden width 64, kernel size 7, dilations `[1,2,4,8,16,32]`, and symmetric zero padding `3×dilation` in each block, followed by `Conv1d(64,C_contacts,kernel_size=1)`. Its theoretical receptive field is 379 samples, so every output can use the full 200-sample window. This fixed project-defined alternative is not presented as a NeuroFlowNet reproduction.
6. **Conditional-flow baseline:** clean-room implementation of the published NeuroFlowNet method family, the primary model under evaluation.

The flow uses `N_scales=2`, `N_steps=6` per scale, `C_hidden=128`, 8 attention heads, AdamW learning rate `1e−3`, weight decay `1e−2`, batch size at most 128 (retain a final partial batch), maximum 100 epochs, and early-stopping patience 10. In each affine coupling network, concatenate the unchanged target half and eight scalp context channels; apply `Conv1d(kernel=3,padding=1,bias=True) → ReLU`, then `Conv1d(kernel=1,bias=True) → ReLU`, transpose to `[batch,time,hidden]`, apply PyTorch multi-head self-attention with 8 heads, no attention mask, no dropout, and no residual connection, transpose back, then `Conv1d(kernel=3,padding=1,bias=True)` to produce shift and log-scale. Use PyTorch default layer initialization, seed all random generators as specified below, apply `τ=10·tanh(raw_τ)` and clamp `σ` to `[-5,5]`. These source-informed choices pin the clean-room implementation; they do not make it an exact reproduction. The paper prose says `tanh` alone while its algorithm and inspected source use the factor 10. Do not search over architecture values. Use QR orthogonal initialization for each invertible channel-mixing matrix and verify its determinant and inverse numerically before fitting. The coupling inverse must be the algebraically correct `x_b=z_b·exp(−σ)−τ`, not the printed Eq. 4/Algorithm 2 expression. For odd channel counts, split `C` into `floor(C/2)` and `ceil(C/2)`, transform the latter, and factor out the first `floor(C/2)` channels at each of two scales; concatenate the final remainder with the factored parts. This is an explicit adaptation for the metadata-verified 62-contact configuration, which the inspected source repository's divisibility assertion does not accept.

Train both temporal CNNs on elementwise mean-squared error in training-standardized targets, AdamW at `1e−3`, weight decay `1e−2`, batch size at most 128, maximum 100 epochs, and patience 10, using validation NRMSE for stopping. The flow uses validation negative log likelihood for stopping. These are fixed training recipes, not equally tuned model searches; report that limitation. Choose the strongest non-flow point comparator from training mean, pointwise ridge, shallow CNN, and full-window CNN by mean inner-validation NRMSE; resolve ties in that order. Keep individual results visible.

Use three training seeds for each stochastic neural model (flow and both CNNs). Derive each as `uint32_be(SHA256("TrackB-v1|" + run_id + "|" + participant + "|" + held_load + "|" + model_name + "|" + replicate_index)[0:4])`; matching replicate indices identify paired fits. The mean and empirical marginal baselines are deterministic. Derive flow-draw and empirical-baseline-draw seeds by the same namespaced SHA-256 convention, including model name and draw index, and generate draws with NumPy `PCG64`. Seed Python, NumPy, PyTorch CPU, and CUDA; request deterministic PyTorch algorithms and disable cuDNN benchmarking. If a required operation has no deterministic implementation, mark that fit failed; do not silently relax determinism or switch hardware. Select each stochastic model's best epoch by its stated inner-validation objective with patience 10; set its final outer-training epoch count to the median of its six inner-fit best epochs (two inner directions × three seeds), rounded up to the next integer and capped at 100. Select ridge λ by mean NRMSE across the two inner directions, averaging within each direction first; ties select the smaller λ. If an inner fit has no finite validation score, that model/configuration fails the outer fold; do not omit only its failed seed or direction. All three seeds must complete for a neural model's fold score. Retries are prohibited except resuming an identical run after an infrastructure interruption before any fit output was written; record the interruption and hashes. If a comparator cannot be implemented, keep the failure and narrow the claim before confirmation rather than silently omitting it. WBEN regional-network scores are not comparable to contact-waveform prediction.

## 6. Candidate metrics and uncertainty

All primary metrics are computed per participant first. Contacts, time points, and windows are repeated measurements, not independent biological subjects. Within each outer load fold, standardize every channel with training-fold statistics only. For each trained flow replicate, generate 100 conditional draws using the flow-draw seed derivation in §5; the point prediction is their mean, and draws are retained for distribution metrics. Generate 100 draws from the no-input empirical marginal baseline using its prespecified PCG64 seed. Restore predictions to microvolts using training-target statistics only, never held-load target statistics. Deterministic point-model predictions are transformed with those same training-only target statistics.

- **Primary point-prediction score:** for participant `p`, held load `k`, contact `c`, held-load window `j`, and within-window sample `t`, compute `NRMSE[p,k,c] = sqrt(mean_{j,t}((x_hat[p,k,c,j,t] - x[p,k,c,j,t])^2)) / SD_train[p,c]`, where `SD_train[p,c]` is computed from the two training loads. Macro-average equally across eligible contacts, then across the three held-load folds to obtain one score per participant. The primary paired contrast is CNF minus the strongest non-flow comparator selected by mean inner-validation NRMSE, without consulting held-load outcomes; negative values favor CNF. Report all individual participant scores, the paired participant-bootstrap 95% interval, and the unnormalized RMSE in microvolts as a secondary metric.
- **Predictive-distribution score:** empirical marginal CRPS at each target coordinate from `M=100` fixed-seed draws, `mean_m |x_m−y| − (1/(2M²)) sum_{m,n}|x_m−x_n|`, calculated in training-standardized units and macro-averaged using the same contact/load/participant hierarchy. Score the flow against the no-input empirical marginal baseline. This coordinatewise baseline does not model joint temporal or cross-contact dependence. Report held-load negative log-likelihood only if the implementation's density and unit Jacobian are independently verified.
- **Reliability:** empirical marginal 50%, 80%, and 90% interval coverage with mean interval width, computed from `numpy.quantile(method='linear')` on the same fixed draws and reported by participant/load/contact. Report width in training-standardized units and microvolts. These are marginal quantities; do not equate them with simultaneous multichannel or whole-waveform coverage. Coverage and width are descriptive; no post-hoc calibration or acceptance threshold is proposed.
- Compute point, CRPS, coverage, and interval-width metrics separately for each of the three flow training seeds. Average the three seed-specific metrics equally within each participant/load/contact before contact and load aggregation, and retain seed-level values for inspection. Do not pool draws across training seeds or treat seeds as independent participants.
- Do not apply conformal or other post-hoc calibration in the primary analysis. It would add a second method and a new calibration split whose validity under held-load shift is not established. Report the flow's raw marginal coverage and interval width as diagnostics only.
- **Population uncertainty:** bootstrap participants, not windows, contacts, or samples. With a small participant count, show individual participant effects and the interval method; do not interpret a wide or unstable interval as evidence of no effect.

For group-level reliability summaries, first average contact-level coverage and width equally within each participant/load, then average the three load folds within participant. Report these participant summaries, a participant-bootstrap 95% interval, and all per-participant/load/contact values. Also report load-specific participant summaries so opposing errors across loads cannot cancel in the overall mean. Do not let participants with more contacts, windows, or samples receive greater weight.

The paired participant-bootstrap confidence interval is the primary uncertainty summary. With three load folds, first average within each participant, then bootstrap participants; never treat the three folds or windows as independent. Use 10,000 participant bootstrap resamples with seed `20261023` and percentile 95% interval; also show every participant's paired effect. If fewer than two participants have complete paired results, do not report a group bootstrap interval. Report both the eligible-participant count and the complete-paired-result count. Treat the confirmation cohort as a small-sample challenge, not a population-wide clinical validation. The primary contrast is descriptive with uncertainty; do not assert superiority or clinical value. The exact eligibility, channel-failure, and metric implementation rules below remain subject to review before B2 can pass.

## 8. Falsification and failure routes

The candidate contribution fails or narrows if any of the following occurs:

- Data semantics or trial counts do not support a leakage-safe held-load split.
- The clean-room flow cannot be implemented from the paper well enough for a meaningful comparison.
- The model's apparent physical-amplitude performance depends on test-target scale. Raw coverage and width are reported descriptively, without post-hoc repair or an undefined “useful operating point” threshold.
- The result is driven by one participant, a single load, or non-independent windows.
- A fair matched baseline performs as well or better; this falsifies an added-value claim for the flow on this task but remains a valid benchmark outcome.
- Correctly paired scalp input does not improve the prespecified score over the real-trial pairing control; this narrows claims about trial-specific scalp information but does not demonstrate zero information in other recordings or tasks.
- Primary-source review shows the exact held-load endpoint is already established; in that case retain only a rigorously bounded reproduction/benchmark if it remains useful, without novelty language.
