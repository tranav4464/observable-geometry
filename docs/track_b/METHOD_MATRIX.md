**NeuroFlowNet fidelity update:** The paper's Eq. 1 forward affine map is not inverted by its printed Eq. 4/Algorithm 2. The pinned public source uses the algebraically correct inverse, `z_b exp(-σ) − τ`; the independent implementation must use and verify that inverse, clearly documenting the correction. **Historical WBEN notes:** The following window, model-order, and 50-Hz preprocessing records were written for the superseded WBEN route. Preserve them for audit history; they do not define the active 200-Hz NeuroFlowNet preprocessing contract.

**Window mapping update (23 October 2026):** WBEN Appendix A.4 directly defines fixation `[0,1)`, encoding `[1,3)`, maintenance `[3,6)`, and response `[6,8)` in the 8-second event epoch and says its analysis uses the final two seconds of maintenance. The candidate held-load challenge therefore uses `[4,6)` seconds from epoch onset (100 samples at 50 Hz), matching the WBEN paper's window. Boran et al. independently reports this phase timing and last-two-second spectra; the aligned NEMAR companion places probe onset at epoch +6 s. This confirms the window choice, not preprocessing fidelity, method novelty, or an empirical result. The WBEN paper specifies downsampling to 50 Hz but not the filter/resampling implementation. See `outputs/track_b/20261022T204000Z_b2_maintenance_window_mapping/`.

**Sequence/model-order constraint (23 October 2026):** WBEN Appendix A.4 specifies a second-order VAR for its real-data analysis. The current local `fit_wben_k1` is first-order and fits one contiguous sequence, so it cannot be applied to concatenated trials without creating false transitions. The held-load candidate requires order-2, independent trial sequences, and per-trial initial states; the companion-state process covariance is singular by construction, which the current positive-definite-only validation does not support. See `outputs/track_b/20261022T205200Z_b2_multisequence_contract/SESSION.md`. This is an implementation prerequisite, not a new method claim.

**Preprocessing/score candidate (23 October 2026):** A transparent candidate uses SciPy 1.18.1 `resample_poly` on each full 8-s epoch (200→50 Hz EEG and 2,000→50 Hz iEEG), then crops `[200:300]`; the default zero-phase Kaiser FIR is specified, while the original WBEN filter remains unknown. The candidate primary score is training-SD-normalized RMSE, macro-averaged across contacts and loads within participants, with a paired contrast against direct ridge and a training-mean reference. See `outputs/track_b/20261022T210500Z_b2_preprocessing_score_contract/SESSION.md`. This contract remains provisional pending tuning/noise/missing-data review and an independent challenge.

## Development-only atlas-mapping feasibility update (23 October 2026)

The earlier lookup of 760 development contacts against the Nilearn Harvard–Oxford MNI152NLin6Asym atlas returned 374 labels (49.2%), but this result is **withdrawn as anatomical evidence**. The dataset authors' source pipeline uses SPM12 OldNorm's linear ICBM152-derived template; the lookup treated those coordinates as if they were already in MNI152NLin6Asym and applied no transform. The archived count is not a feasibility result and cannot support target selection, atlas claims, or WBEN's observation matrix. See the superseding audit in `outputs/track_b/20261024T_b2_coordinate_space_review/` and `B2_FORMAL_SPEC.md`.

The [WBEN source paper](https://openreview.net/pdf/799e82c424dc3dcfa7cfcf45da2f0882ca3ef973.pdf) specifies nearest-neighbor aggregation of source locations into 69 HO regions, then says iEEG channels are assigned from electrode positions, signals assigned to a region are averaged, and `C` is a binary selection matrix. The accessible method text does not operationalize the exact contact-to-region nearest-neighbor target, tie handling, maximum distance, or outside-atlas handling. Therefore the 374-contact point-in-label result is not a reproduction of WBEN's mapping. The regional baseline implementation must preserve this mapping ambiguity or resolve it from primary supplementary material / an official implementation before it can be called faithful.

## Atlas-free contact-level fallback screen (23 October 2026)

The development metadata now show that every SEEG channel label joins to an electrode row and that the same set of labels is present in all available sessions for each development participant: 48 contacts across 4 sessions for sub-01, 64 across 7 for sub-02, and 40 across 3 for sub-03. This supports a within-participant signal-prediction target defined by channel name, without assigning contacts to atlas regions. It does not show stable physiology, anatomical truth, usable signal quality, or prediction. The audit is metadata-only: `outputs/track_b/20261022T200500Z_b2_contact_stability_audit/`.

The candidate question is whether a participant-specific state-space model trained on paired recordings at two working-memory set sizes can predict the recorded iEEG contact waveforms from scalp EEG alone at the third held-out set size. Development counts favor a held-load-only split (44 minimum, 61 median test trials) over a joint held-load/held-session split (7 minimum), because it tests one source of shift at a time. This is within-participant calibration: it does not test unseen people without iEEG calibration or session transfer. Direct methods already occupy within-participant waveform reconstruction (NeuroFlowNet), calibrated cross-participant waveform reconstruction (CAST), and scalp-to-iEEG spectral feature prediction (Subramanian et al.). The held-load task is an empirical challenge, not a new algorithm. The proposed contact-state model is explicitly a WBEN-inspired adaptation, not the paper's 69-region WBEN reproduction.

An atlas-free model with contact-level latent states would be a WBEN-inspired adaptation, not faithful WBEN, because the published method's state nodes are 69 HO regions and its `C` operator averages contacts assigned to each region. If this route is selected, preserve WBEN as a separate regional reproduction/challenge only if its target map is defensible; otherwise compare the contact-level model with direct predictors and name the change accurately. No novelty claim is justified at this stage.

**Coordinate provenance check:** the released `*_electrodes.json` calls x/y/z MNI coordinates and says the accompanying anatomical labels were assigned using Brainnetome. Boran et al. 2020 describe CT/T1 localization, MNI normalization, and Brainnetome annotation, including manual anatomical labels in some cases. However, the 14 development electrode tables have no `space-<label>` filename entity or inherited `*_coordsystem.json` sidecar. Current BIDS iEEG specification requires the coordinate-system sidecar and uses it to record coordinate system and units. WBEN additionally says EEG and iEEG electrodes were co-registered to `fsaverage`. These records establish intent to use MNI/Brainnetome and a separate WBEN template statement, but do not provide a traceable transform connecting released contact coordinates to the WBEN HO observation matrix. See `scripts/track_b/audit_dev_coordinate_provenance.py` and `outputs/track_b/20261022T191530Z_b2_coordinate_provenance/SESSION.md`.

### Load-conditioned dynamics audit (22 October 2026)

Condition-dependent latent dynamics are established by Conditionally Linear Dynamical Systems, which learn `A(u)` and related state-space parameters from experimental covariates. Load-dependent connectivity has also been studied in working-memory tasks, and Yang et al. report iEEG load decoding across set sizes 4, 6, and 8 for the same task family. Therefore a load-specific or linearly modulated transition matrix is not a mathematical novelty claim. It may be retained as a comparator or useful extension only if it adds held-out real-data value under matched evaluation. Full bounded audit: `outputs/track_b/20261022T201900Z_b2_load_modulated_state_space_prior_audit/SESSION.md`; primary sources therein.


## Split-feasibility update (23 October 2026)

A development-only metadata audit found that a joint held-load/held-session split yields 42 folds with a minimum of only 7 artifact-unflagged test trials. Separate designs avoid mixing two kinds of distribution shift: held-load transfer has 9 nonempty folds across the three development participants (44 minimum, 61 median test trials), while held-session transfer has 14 nonempty folds (39 minimum, 46 median test trials). These counts do not establish statistical power. The held-load design tests transfer only to an unseen set size within sessions represented in training; the held-session design tests session transfer with all loads represented during training. They must remain separate estimands. See `outputs/track_b/20261022T202100Z_b2_joint_fold_feasibility/` and `outputs/track_b/20261022T202200Z_b2_split_alternatives/`.
