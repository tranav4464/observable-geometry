# Research evidence

This directory contains the curated research records committed with the software. It is not part of the installed Python package. The larger working research archive may exist beside the repository in the full TKS workspace and is intentionally not presented as portable package evidence.

- `gbf_omitted_activity_20261024/` contains the research records selected for this repository snapshot.
- Current accepted software claims are summarized in [`../README.md`](../README.md) and [`../docs/tks/submission.md`](../docs/tks/submission.md).
- Gate status and evidence paths are recorded in [`../docs/track_b/GATE_REGISTER.json`](../docs/track_b/GATE_REGISTER.json).

Research files may describe negative results, superseded routes, or conditional model findings. Read the associated protocol and limitations before interpreting an individual result.
