# Historical WBEN and synthetic-signal artifacts

These files document a superseded NeuroFlowNet/WBEN exploration that predates the active GBFs software build. They are retained for auditability and Git history only. They are not part of the installed package, are not in the active test path, must not be run as part of this project, and do not count as empirical evidence. The active project uses measured recordings only; algebraic fixtures in the active tests are software checks, not neuroscience results.

The archived Python scripts may reference earlier source paths and run outputs. Do not attempt to execute them from this archive.
